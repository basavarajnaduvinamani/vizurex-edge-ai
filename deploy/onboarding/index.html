VisureX is a prototype in active development. Plants, parts and records on this site are demo data.

AI quality inspection for MSME manufacturing

Built at WCTE, IIT Madras, to improve quality-inspection workflows across its network of 50+ MSMEs.

How it works

  1. CaptureTake a photo on a phone.
  2. CheckRun the DINOv2 check in the browser.
  3. RecordOpen an NCR for a defect.
  4. AssignGive the corrective action an owner.
  5. CloseAttach an after-photo to close the action.

NCR means nonconformance report. The demo plants are fictional. Records and redacted photos are stored in this browser.

What has been checked

In the browser: the DINOv2 model runs as ONNX in WebAssembly. It matched the Python reference on 20 of 20 decisions, with a median check time of 361 ms on a laptop CPU. Browser test results

On Android: the PatchCore ONNX export matched 261 of 261 decisions at 163-168 ms on CPU.

On glasses: a Kotlin bridge for Ray-Ban Meta (Meta Wearables toolkit 1.0.1) has 23 unit tests and an emulator test. It has not been run on glasses yet.

Blurry photos: blur makes the detector flag every image as defective, so the app asks for a retake before scoring.

What did not work: a pre-registered router meant to choose between DINOv2 and PatchCore failed. It is reported as a negative result.
