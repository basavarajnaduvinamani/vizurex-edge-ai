# VisureX design plan

## Pass one

Audience: a quality lead at a small Indian manufacturer and a recruiter with one minute. Lead with a real inspection of a generated washer.

Palette: blueprint ink `#162B3B`, steel text `#43596A`, bench paper `#F2F6F8`, form white `#FFFFFF`, signal blue `#174D72`, rule steel `#788E9E`.
Type: Segoe UI for instructions and form controls. Bahnschrift for the product mark, headings, and compact instrument readings. Local fallbacks keep loading predictable.

Desktop aligns the left edge of every section to the inspection bench. On mobile, the controls follow the image and the rest becomes a single column.

```text
VisureX              Home Inspect Walk NCR Actions Dashboard
Shop-floor inspection                          Theme / GitHub
+-----------------------------------------------------------+
| Generated washer image  | Part selector                  |
|                         | Test image selector            |
| Image / heatmap         | Run inspection                 |
|                         | Decision slip and next action  |
+-----------------------------------------------------------+
  How it works           Capture / Check / NCR / Action / Close
  Results                Two benchmark points with CI whiskers
  About                  Affiliation and runtime evidence
```

1. Put the real decision first. The washer, controls, and decision slip form one inspection bench.
2. Treat forms like shop-floor records. Give labels, ownership, and closure evidence clear positions.
3. Keep evidence next to the claim. Pair each benchmark point with its interval and keep the benchmark separate from the demo verdict.

## Pass two

Replaced the initial hero headline and stat-strip idea with the actual washer and a decision slip that changes after a run. Replaced a grid of feature cards with a numbered work sequence and a single labelled interval plot. Avoided cream and clay, neon, editorial columns, decorative eyebrows, and motion. The blue bench frame is the only bold composition. Numbering belongs to the actual five-step workflow.
